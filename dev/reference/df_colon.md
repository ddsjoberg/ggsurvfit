# Formatted Copy of `survival::colon`

This is a copy of the colon data set exported by the survival package.
This data set, however, has column labels, numeric categorical variables
are now factors with assigned levels, and we only include the recurrence
outcome.

## Usage

``` r
df_colon
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 929
rows and 14 columns.

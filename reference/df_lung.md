# Formatted Copy of `survival::lung`

This is a copy of the lung data set exported by the survival package.
This data set, however, has column labels and numeric categorical
variables are now factors with assigned levels.

## Usage

``` r
df_lung
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 228
rows and 10 columns.
